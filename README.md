# BRGY-AI — Manual QA Documentation

## Project Overview

**BRGY-AI: RAG-Based Legal Information and Document Assistance for Barangay 134** is an academic capstone project designed to assist barangay residents in accessing legal information and preparing barangay-related documents.

The system utilizes Retrieval-Augmented Generation (RAG) to provide context-based legal information while supporting existing barangay processes.

## My Role — Manual QA Contributor

As a member of the capstone development team, I participated in the manual testing and evaluation of the BRGY-AI application.

The team's testing documentation contains **92 test cases**, with **37 test cases attributed to me**.

My contributions included participating in application testing, checking system functionality against expected results, and documenting test scenarios and outcomes.

## Features Tested

My assigned test cases covered the following modules:

- **Resident Registration** — Validating account creation and required field inputs.
- **Login and Authentication** — Checking user login functionality and validation behavior.
- **Home Screen** — Verifying navigation and interface functionality.
- **Announcements** — Checking the display and accessibility of barangay announcements.
- **Complaints** — Testing selected complaint-related functionalities.

## Testing Methodology

The project utilized **manual functional testing**, with test cases organized and documented using Google Sheets.

Each test case includes relevant testing information such as:

- Test Case ID
- Module and Test Scenario
- Preconditions
- Test Steps
- Expected Results
- Recorded Test Results
- Assigned Tester

Testing was performed by following documented procedures and comparing observed application behavior with the expected results.
